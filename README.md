# Secure Login System

A secure login web app built with Flask and SQLite.

## Key Features
- **User registration and login** using bcrypt-hashed passwords
- **Basic input validation** and protection from SQL injection through parameterized queries
- **Session management** with a logout feature
- **Optional: Two-Factor Authentication (2FA)** using TOTP (available in the full version)

## Expected Outcome
A secure login system with hashed passwords, input validation, session management, and optional 2FA significantly reduces unauthorized access and protects user accounts from common attacks.# Thiranex_task-4
